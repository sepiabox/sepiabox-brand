# sepiabox-brand

The Sepiabox name, logo, colors and type, and the rules for using them.

## The name

| Where | Write |
|---|---|
| Sentences, titles, documents, app stores | **Sepiabox** |
| The logo | **sepiabox**, lowercase, drawn |
| Addresses: domain, GitHub, email, packages | `sepiabox` |
| .NET namespaces | `Sepiabox.*` |

Never: SepiaBox, Sepia Box, sepia-box.

## The symbol

An old photo held by album photo corners: the family photo box, organized.

| File | Use |
|---|---|
| [`assets/symbol.svg`](assets/symbol.svg) | On light backgrounds |
| [`assets/symbol-dark.svg`](assets/symbol-dark.svg) | On dark backgrounds |
| [`assets/symbol-small.svg`](assets/symbol-small.svg) | Favicons (48, 32 and 16 px) and anything under 48 px: the print is solid, without the white frame |
| [`assets/symbol-mono.svg`](assets/symbol-mono.svg) | One-color printing and embossing |
| [`assets/app-icon.svg`](assets/app-icon.svg) | App icons: the dark-background symbol on a Developer rounded square |

The wordmark is "sepiabox" in Bricolage Grotesque ExtraBold (800), letter spacing −0.045 em, with "sepia" in Sepia and "box" in Developer. On dark backgrounds "sepia" is `#D59B67` and "box" Silver paper `#EEECE7`. An outlined SVG of the wordmark is still to be exported.

## Colors

Two old photographic processes on silver photo paper.

| Name | Hex | Role |
|---|---|---|
| Sepia | `#9A5A2C` | Brand |
| Cyanotype | `#1F4C74` | Buttons, actions and links (hover `#163A59`) |
| Developer | `#231A14` | Text |
| Silver paper | `#EEECE7` | Background |
| Frame | `#D8D1C6` | Lines and borders |

On dark backgrounds, Sepia becomes `#D59B67` and the print inside the symbol `#C98A55`.

Supporting tones: surface `#F8F7F4` (cards on Silver paper), body text `#3D332C`, secondary text `#5C5048`, and `#E6EBF0` behind filter chips, whose text is Cyanotype.

## Type

- **Bricolage Grotesque** for titles (500, 700, 800)
- **Figtree** for body text (400, 500, 600)
- **IBM Plex Mono** for filters, dates and metadata

All three are free on Google Fonts under the SIL Open Font License.
